# C++ TCP Network Homework

Проект объединяет задания №1, №2 и №3.

## Задание №1
Изучение Socket API и UML-взаимодействия клиента и сервера по TCP.

## Задание №2
Синхронный TCP Echo Server: один клиент за раз, строка возвращается в верхнем регистре.

Порт: 54000.

## Задание №3
Асинхронная версия сервера из задания №2. Используются неблокирующие сокеты и список подключённых клиентов. Отключение одного клиента не останавливает сервер.

Порт: 54001.

## Сборка
Проект рассчитан на Windows и использует Winsock API. Для CMake нужен стандарт C++17.
