# Отчет по заданию №3. Асинхронный сервер

## Цель работы
Переделать сервер из задания №2 на асинхронную работу и обеспечить одновременную обработку нескольких клиентов.

## Ход работы
В основу взят сервер из задания №2. Сокеты переведены в неблокирующий режим. Сервер циклически проверяет подключения и данные от клиентов, поэтому один клиент не блокирует остальных.

## Обработка отключения
При отключении клиента его сокет закрывается и удаляется из списка. Сервер продолжает работу.

## Результат
Можно одновременно подключить несколько клиентов. Каждый получает ответ в верхнем регистре. Отключение одного клиента не завершает сервер.

## Вывод
Синхронный сервер расширен до асинхронного варианта с поддержкой нескольких клиентов и обработкой отключений.
