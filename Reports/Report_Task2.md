# Отчет по заданию №2. Базовый синхронный сервер

## Цель работы
Создать синхронный TCP Echo Server и клиент. Сервер получает строку и возвращает её в верхнем регистре.

## Ход работы
Создан сервер на C++ с использованием Winsock. Сервер работает в блокирующем режиме и обрабатывает одного клиента за раз. Клиент подключается, отправляет строку и получает ответ.

## Результат
Например: `hello server` → `HELLO SERVER`.

## Вывод
Синхронный TCP-сервер принимает сообщения, переводит их в верхний регистр и отправляет обратно.
