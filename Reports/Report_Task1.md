# Отчет по заданию №1. Анализ и проектирование

## Цель работы
Изучить Socket API в C++ и рассмотреть взаимодействие клиента и TCP-сервера.

## Socket API
Для Windows используется Winsock API. Основные функции: `WSAStartup()` — запуск Winsock, `socket()` — создание сокета, `bind()` — привязка адреса и порта, `listen()` — ожидание подключений, `accept()` — принятие клиента, `connect()` — подключение, `send()`/`recv()` — обмен данными, `closesocket()` — закрытие.

## Компоненты
Сервер создаёт сокет, привязывает его к адресу и порту и ожидает клиента. Клиент создаёт сокет и подключается к серверу. После подключения выполняется обмен данными.
